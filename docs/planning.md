# Personal Portfolio — Project Plan

## Purpose and Audience
Create a professional portfolio for potential employers and recruiters.
Present my software development skills, projects, education and
engineering experience.

## Starting Point
Extend the completed Modern CV project, which uses HTML and CSS.
Reuse and adapt its content and styling while introducing React.

## Page Structure
Use a single-page layout with navigation links to these sections:

1. Introduction — name, professional title and short introduction
2. About — professional background and software development studies
3. Skills — software development, programming and engineering
4. Projects — examples of completed work
5. Experience — relevant professional experience
6. Education — qualifications and current training
7. Contact — email and GitHub links

Include a footer with copyright and a back-to-top link.

## Projects to Showcase
- Inventory Management System
- Asset Tracking
- Modern CV
- NordicBrew

Each project card will include a name, short description, technologies,
screenshot and GitHub link. Include a live demo link where available.

## Design
- Retain the Modern CV's green accents and light grey backgrounds.
- Use consistent typography, spacing and headings.
- Give projects a prominent position.
- Adapt the layout for desktop, tablet and mobile.
- Use semantic HTML, descriptive image text and visible keyboard focus.
- Create a basic wireframe before coding.

## React Structure
- Divide the page into components for its main sections.
- Use a reusable ProjectCard component.
- Store project information separately in an array of objects.
- Use section links for navigation; React Router is not needed initially.

## Scalability and Extensibility
- Add projects through data entries without duplicating card markup.
- Give each project a stable, unique ID.
- Keep components focused and easy to update independently.
- Use shared CSS variables for colours and spacing.
- Allow future additions such as filtering and project detail pages.

## Testing and Publication
- Check desktop, tablet and mobile layouts.
- Test navigation, links and keyboard access.
- Check for missing images and browser console errors.
- Replace placeholder contact details before publication.
- Publish the code in a public GitHub repository.
- Deploy the portfolio and verify the live website.

## Documentation and Presentation
- Keep this planning file concise.
- Write a README covering the project, technologies, setup and links.
- Prepare a short presentation after completing the website.
- Submit the GitHub repository URL and live portfolio URL.
